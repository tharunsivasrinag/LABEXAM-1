KLECommerce Login -> Products website

Files:
- index.html: Login page (first page)
- user.html: Product selection page
- admin.html: Demo admin product form
- style.css: Shared styling
- script.js: Login navigation, cart count, and admin form demo

Run:
1. Extract the ZIP.
2. Open the folder in VS Code.
3. Open index.html with Live Server (recommended), or double-click index.html.
4. Fill in the login form and press Login. It will open user.html.
5. Click Add to Cart to see the cart count increase.

Important: Login is a front-end demo, not real account authentication. Admin products are not saved to a database, and the cart count resets when the page reloads.
